# Fake News Detection EDA

Exploratory data analysis on fake and true news article datasets.

## What's in this repo
- `Fake News Detection Analysis.ipynb"` - the full analysis: data cleaning, preprocessing, EDA, insights, recommendations, and conclusion
- `data/` - the raw CSV files used (Fake.csv, True.csv)

## Tools used
Python, pandas, matplotlib, seaborn, nltk
